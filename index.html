Without durable memory

Every new session pays the rediscovery cost.

  • re-read old threads and documents
  • ask the same “why?” again
  • risk acting on a stale or forgotten convention

With Vault

The next task starts with the relevant past.

  • retrieve the decision when it matters
  • prepare a bounded, inspectable context block
  • mark guidance useful or followed
Value without invented numbers

Show how production value could be measured.

This page proves the memory loop, not a customer savings number. It does not make an LLM call or pretend to know a dollar saving. Real deployments can measure that separately.

Perseus can send provider-reported usage and the counterfactual prompt it replaced to Perseus Ledger / Plutus. Provider-billed events with a recorded baseline become re-computable savings; context-only reductions stay in a separate estimate arm with coverage and counting exactness shown.
